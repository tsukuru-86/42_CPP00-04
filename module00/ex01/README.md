このREADMEは、CPP Module 00課題文のChapter II（General rules）とChapter V（Exercise 01）に沿ったレビュー用メモです。

| 項目 | 課題文の指定 |

## 課題文の共通規則

- `c++ -Wall -Wextra -Werror` でコンパイルする
- `-std=c++98` を追加してもコンパイルできること
- クラス名はUpperCamelCaseにし、クラスを含むファイル名をクラス名に合わせる
- 特に指定がなければ、出力は標準出力へ表示し、各メッセージを改行で終える
- 外部ライブラリ、C++11以降、Boostを使わない
- `*printf()`、`*alloc()`、`free()`を使わない
- `using namespace` と `friend` を使わない
- Module 08より前ではSTLのコンテナとアルゴリズムを使わない
- ヘッダ内に関数実装を書かず、必要な依存を含め、include guardを付ける
- C課題と同じMakefile規則に従う

## 課題文が求めるクラス

### `PhoneBook`

- `Contact` の配列を持つ
- 最大8件を保存する
- 9件目を追加すると、最も古い連絡先を置き換える
- 連絡先保存のための動的確保を使わない

### `Contact`

- 電話帳の1件の連絡先を表す

コード上の電話帳は `PhoneBook` クラスのインスタンス、各連絡先は `Contact` クラスのインスタンスでなければなりません。常にクラス内部だけで使うものは `private`、外部から使えるものは `public` にするよう求められています。

## 課題文が求めるコマンド

プログラム開始時の電話帳は空です。受け付けるコマンドは `ADD`、`SEARCH`、`EXIT` の3つだけです。

### `ADD`

1. first name
2. last name
3. nickname
4. phone number
5. darkest secret

上記を1項目ずつ入力させ、全項目の入力完了後に連絡先を保存します。保存済みの連絡先に空の項目を含めることはできません。

### `SEARCH`

最初に、保存済みの連絡先を次の4列で一覧表示します。

| 列 | 表示規則 |
|---|---|
| index | 幅10文字、右寄せ |
| first name | 幅10文字、右寄せ |
| last name | 幅10文字、右寄せ |
| nickname | 幅10文字、右寄せ |

- 各列を `|` で区切る
- 10文字を超える文字列は切り詰め、表示できる最後の文字を `.` にする
- 一覧の後、表示する連絡先のindexを入力させる
- indexが有効なら、連絡先の各項目を1行ずつ表示する
- indexが範囲外または不正なら、適切な動作を定義する
- 表示の再現には `<iomanip>` を使う

### `EXIT`

プログラムを終了します。保存されていた連絡先は失われます。

### その他の入力

課題文では、`ADD`、`SEARCH`、`EXIT` 以外の入力は無視すると指定されています。正しいコマンドを実行した後は次のコマンドを待ち、`EXIT` が入力されるまで継続します。

実行ファイル名は固定されておらず、「適切な名前」を付けるよう指定されています。この提出では `phonebook` です。

## レビュー手順

```sh
make fclean
make
./phonebook
```

次の順で確認します。

1. 起動直後に `SEARCH` を実行する
2. `ADD` で、10文字以下と11文字以上の値を含む連絡先を追加する
3. 空の項目を入力し、空欄の連絡先が保存されないことを確認する
4. `SEARCH` で4列の幅、右寄せ、`|`、末尾の `.` を確認する
5. 有効なindexで5項目が1行ずつ表示されることを確認する
6. 範囲外および数値でないindexで、定義された処理になることを確認する
7. 9件追加し、最も古い連絡先が置き換わることを確認する
8. 未定義コマンドの後も電話帳の状態が変わらず、次の入力を待つことを確認する
9. `EXIT` で終了する

## チェックリスト

- [ ] `PhoneBook` と `Contact` がそれぞれクラスとして実装されている
- [ ] クラス名とファイル名が共通命名規則に従っている
- [ ] 電話帳が固定長8件の配列を持ち、動的確保を使っていない
- [ ] 5項目すべての入力後にだけ連絡先を保存する
- [ ] 保存済みの連絡先に空の項目がない
- [ ] 9件目が最も古い連絡先を置き換える
- [ ] `SEARCH` の4列が幅10文字、右寄せ、`|` 区切りである
- [ ] 10文字を超える値が先頭9文字と `.` で表示される
- [ ] 有効なindexの全項目が1行ずつ表示される
- [ ] 不正なindexに対する動作が定義され、異常終了しない
- [ ] `ADD`, `SEARCH`, `EXIT` 以外で電話帳の操作を実行しない
- [ ] 共通禁止事項に違反していない
- [ ] Makefileの `all`, `clean`, `fclean`, `re` が動作する

## 課題文が指定していないこと

- プロンプトやエラーメッセージの具体的な文言
- 不正なindexに対する具体的な処理内容
- 8件を超えた後、残っている連絡先を一覧に並べる順序
- 実行ファイルの固定名

したがって、これらは課題文の明示要件と矛盾せず、一覧のindexと詳細表示が対応していれば、実装側で定義できます。

## この提出の実装メモ

この実装では、固定長配列を循環バッファとして使い、8件を超えた後も現在保存されている連絡先を古い順に表示します。画面上のindexと内部配列の位置を一覧・詳細表示の両方で同じように変換しています。これは課題文が指定した表示順ではなく、この提出で選択した一貫した動作です。
